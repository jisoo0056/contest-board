# 공모전 모아보기

문화기획 · 문화정책 · 브랜드 · 공공문제 분야 공모전과 서포터즈·대외활동을 하루 한 번(아침 7~8시 전후) 자동으로 모아서 보여주는 사이트입니다.

- **목록 순서**: **NEW**(최근 3일 안에 새로 잡힌 것) → **접수 중**(마감 임박 순) → **접수 시작 전**(시작일 순). 마감된 공모전은 맨 아래 '마감된 공모전'에 회색으로 모아 둠
- **형태 탭**: 아이디어 제안 / 기획서 / 영상·디자인 등 결과물 / 서포터즈 / 대외활동
- **분야 필터**: 문화기획 · 문화정책 · 브랜드·마케팅 · 공공문제·정책제안
- **참가 자격 필터**: 대학생만 / 일반인 가능 / 청년
- **개인·팀 표시**: 공모전마다 '개인', '팀만', '개인·팀 모두' 배지. 필터로 '팀 참가 가능'만 볼 수도 있음
- **자동으로 빼는 것**: 디자인·사진·UCC·영상·문학·미술·음악·IT·스포츠 공모전, 청소년 전용 공모전, 교육·봉사·캠프·체험단 같은 대외활동
- **이메일 알림**: 새 공모전이 있는 날에만, 채용 알림과 별도 메일로 발송
- **수집 실패 표시**: 사이트가 바뀌어서 못 가져온 곳은 상단 경고 + '출처 목록'에 ⚠ 표시
- PC/휴대폰 둘 다 볼 수 있고, 비용은 0원 (GitHub 무료 기능)

공모전 내용은 복사하지 않고, 제목·주최·기간과 원문 링크만 보여줍니다.

## 처음 한 번만 하는 설정 (약 15분)

채용 모아보기와 거의 같아요. 이미 해본 단계는 금방 끝나요.

### 1. 저장소 만들기
1. GitHub에 로그인 → 오른쪽 위 `+` → **New repository**
2. Repository name: `contest-board` → **Public** 선택 → **Create repository**
3. 이 폴더의 파일을 전부 올립니다. (Claude에게 저장소 이름을 알려주면 대신 올려줄 수 있어요.)

### 2. 비밀값 넣기 (메일 알림용)
저장소 → **Settings** → **Secrets and variables** → **Actions** → **New repository secret** 으로 아래 5개를 하나씩 추가합니다.
채용 모아보기에 넣은 값과 **똑같이** 넣으면 돼요. (공공데이터 API 키는 필요 없어요.)

| Name | 값 |
|---|---|
| `SMTP_HOST` | `smtp.naver.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | 네이버 메일 주소 전체 (예: `myid@naver.com`) |
| `SMTP_PASS` | 네이버 비밀번호 (2단계 인증을 쓰면 애플리케이션 비밀번호) |
| `MAIL_TO` | 알림 받을 메일 주소 |

메일 제목은 `[공모전 모아보기] 새 공모전 N건` 으로 와서 채용 알림과 따로 보여요.

### 3. 사이트 켜기 (GitHub Pages)
저장소 → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main`, 폴더: `/docs` → **Save**
1~2분 뒤 `https://아이디.github.io/contest-board/` 에서 열립니다. 휴대폰에서는 **홈 화면에 추가**해 두면 앱처럼 쓸 수 있어요.

### 4. 첫 수집 실행
저장소 → **Actions** 탭 → (처음이면 활성화 버튼 클릭) → **공모전 수집** → **Run workflow**
5분쯤 뒤 사이트를 새로고침하면 공모전이 보여요.
첫 수집 때 잡힌 공모전은 'NEW'와 메일 없이 기본 목록으로 들어가고, **다음 날부터 새로 올라온 공모전만** NEW 표시와 메일이 와요.

## 사이트에서 분류 고치기 · 기관 추가하기

사이트 오른쪽 위 **⚙(관리 설정)** 에 GitHub 토큰을 한 번 넣으면, 그 기기에서 아래 기능이 켜져요.
- 공모전마다 **형태 바꾸기**, **개인/팀 고치기**(드롭다운), **숨기기**
- '출처 목록' → **+ 기관 추가**, 기관 **삭제**
- **지금 수집 실행** 버튼

**토큰 만드는 법**: GitHub → 오른쪽 위 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
- Repository access: **Only select repositories** → `contest-board`
- Permissions: **Contents: Read and write**, **Actions: Read and write**
- 만든 토큰(`github_pat_…`)을 복사해서 ⚙ 설정에 붙여넣기

(채용 모아보기용 토큰에 `contest-board` 저장소를 추가해도 돼요.)

### 기관 추가 요령
- 기관의 **공지사항·공모 게시판 '목록' 페이지 주소**를 넣으세요.
- 제목에 '공모전', '아이디어 공모', '정책 제안', '서포터즈', '기자단', '네이밍' 같은 말이 있는 글만 가져와요. '지원사업 공모', '기관 선정', '결과 발표' 같은 글은 빼요.

## 알아두면 좋은 점
- **분류는 제목의 단어로 자동 판단**해요. 틀리면 사이트에서 바로 고치세요. 고친 분류는 계속 유지돼요.
- **참가 자격**은 링커리어·콘테스트코리아·위비티에 적힌 대상을 그대로 써요. '대학생만'은 대상에 대학생은 있고 일반인은 없는 경우예요. '청년'은 대상이나 제목에 '청년', '만 19~39세'처럼 적힌 경우예요.
- **개인/팀**은 공고 본문에서 "개인 또는 팀", "3인 이내 팀" 같은 문구를 찾아 표시해요. 본문이 이미지로만 된 공고는 '확인 필요'로 남아요. 서포터즈는 기본으로 '개인'이에요.
- **접수 시작 전**은 접수 시작일이 오늘 이후인 공모전이에요. 시작일이 되면 자동으로 '접수 중'으로 옮겨져요.
- 관심 분야 기준을 바꾸고 싶으면 `scraper/collect.py` 맨 위의 `FIELD_RULES`(분야), `EXCLUDE`(제외 단어), `ACTIVITY_EXCLUDE`(대외활동 제외 단어)를 고치면 돼요. Claude에게 "○○ 공모전도 나오게 해줘"라고 말해도 돼요.
- GitHub 예약 실행은 몇 분~수십 분 늦게 돌 수 있어요.

## 파일 구성
```
docs/                   사이트 (GitHub Pages)
  index.html, app.js, style.css
  data/sources.json     출처 목록 (사이트에서 추가/삭제 가능)
  data/overrides.json   직접 고친 분류/숨김
  data/contests.json    수집된 공모전 (자동 생성)
  data/status.json      출처별 수집 성공/실패 (자동 생성)
scraper/collect.py      수집 프로그램
.github/workflows/collect.yml  매일 자동 실행 설정
```
